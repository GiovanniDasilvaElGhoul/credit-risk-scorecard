# Credit Risk Scorecard & Portfolio Optimization

A MATLAB-based credit risk modeling project for evaluating borrowers,
estimating probability of default, and optimizing a lending portfolio.

## Project Overview

The project builds a credit scoring model using historical customer data
and applies it to a portfolio of loan applicants.

The model uses:

- Weight of Evidence (WOE) binning
- Logistic Regression
- Credit Scorecard Modeling
- ROC / AUC Model Validation
- Probability of Default (PD)
- Optimal Credit Score Cutoff
- Expected Loss (EL)
- Risk-Based Interest Rate Pricing

## Features

The model considers:

- Age
- Residential Status
- Employment Status
- Income

## Methodology

1. Prepare historical customer data
2. Perform automatic variable binning
3. Calculate Weight of Evidence
4. Train a logistic regression credit scorecard
5. Map credit scores between 0 and 100
6. Evaluate the model using ROC/AUC
7. Estimate Probability of Default
8. Determine the optimal acceptance threshold
9. Select low-risk clients
10. Calculate Expected Loss
11. Determine minimum break-even interest rates
